# 📚 Sistema de Gestão de Biblioteca (Study Project)

Este projeto foi desenvolvido como parte dos meus estudos focados em **Back-end Development**, unindo a lógica de programação em PHP com a estruturação de bancos de dados relacionais e interfaces dinâmicas.

---

## 🛠️ Tecnologias e Conceitos Aplicados

### **Back-end & Database**
* ![PHP](https://img.shields.io/badge/PHP-777BB4?style=for-the-badge&logo=php&logoColor=white) 
    * Manipulação de variáveis, sessões e processamento de formulários.
* ![MySQL](https://img.shields.io/badge/MySQL-00000F?style=for-the-badge&logo=mysql&logoColor=white)
    * Modelagem de dados, uso de **JOINs** para relacionar livros e usuários, e consultas estruturadas.
* **Arquitetura de Redes:** Aplicação prática dos conceitos da **Camada de Aplicação (HTTP)** do modelo OSI para comunicação cliente-servidor.

### **Front-end**
* ![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=for-the-badge&logo=html5&logoColor=white)
* ![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=for-the-badge&logo=css3&logoColor=white)
    * Criação de interfaces responsivas e formulários de cadastro validados.

---

## 🚀 Funcionalidades Estudadas

- [x] **CRUD Completo:** Cadastro, Leitura, Atualização e Deleção de livros e usuários.
- [x] **Conectividade:** Implementação de PDO/MySQLi para conexão segura com o banco de dados.
- [x] **Lógica de Autenticação:** Sistema de login para controle de acesso à biblioteca.
- [x] **Consultas Relacionais:** Listagem de empréstimos vinculando IDs de usuários a títulos de livros.

---

## 📖 Como Rodar o Projeto

1.  Certifique-se de ter um servidor local instalado (como **XAMPP** ou **WampServer**).
2.  Clone este repositório na pasta `htdocs` ou `www`.
3.  Importe o arquivo `.sql` fornecido para o seu **phpMyAdmin**.
4.  Configure as credenciais do banco de dados no arquivo `conexao.php`.
5.  Acesse `localhost/Biblioteca-PHP-SQL-HTML-CSS` no seu navegador.
